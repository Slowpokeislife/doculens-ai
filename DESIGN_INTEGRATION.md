# Integration plan — Stitch layouts + Dimension style

- `code(1).html` contributed the product-home layout, feature narrative and demo CTA; all fictional customer logos, SOC2 badges, performance percentages and enterprise adoption claims were removed.
- `code.html` contributed the core workbench: metrics, uploaded version pair, side-by-side annotated changes, and document Q&A. Synchronized scrolling and clause-coordinate navigation are intentionally **not** claimed or implemented.
- `code(2).html` contributed the executive report hierarchy: report heading, findings, metadata, AI summary and an actual download button. Governance gates, Word redline exports, signatory routing and simulated risk verdicts were removed.
- `DESIGN.md` defines surface colors, font rhythm, frosted glass, white pill actions, minimal shadow, restrained hero horizon gradient, monochrome UI and an optional violet line accent.
- Dynamic UI is implemented in Streamlit; Stitch HTML is used as design inspiration, not as fake interactive screens. All actions are real Streamlit controls.
- The core remains the validated v0.2.2 document engine; changes to report colors are cosmetic.
