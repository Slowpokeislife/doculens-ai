# v0.5 — Bilingual Dimension Edition

- Automatic PDF language detection (Spanish/English), plus explicit selection.
- Localized main navigation, workspace labels, report UI, chat prompts and PDF report headings.
- Two and only two built-in demo pairs (one Spanish, one English).
